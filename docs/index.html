01 / THE ESSENTIALS

Move between players

Choose from available MPRIS players. The app follows along as players open, close, and change tracks.

02 / YOUR CHOICE

Control the details

Play, pause, skip, seek, and adjust volume. Shuffle, repeat, and a scrollable queue appear when your player supports them.

03 / FULL CONTROL

Fits your desktop

Switch to compact mode, keep it in the background, or use a status indicator when your desktop supports one.

FEELS RIGHT AT HOME

Made for the Linux desktop.

Built with GTK4 and libadwaita, MPRIS MiniPlayer speaks the same MPRIS language as your favorite media apps. No account, no music library to import, no player lock-in.

GTK4libadwaitaMPRISD-Bus
GET STARTED

Ready when you are.

Download the latest release, pick the package for your system, and press play.

Browse release downloads ↗
◆X86_64

Flatpak

Install the downloaded Flatpak bundle for your user account.

flatpak install --user ./MPRIS-MiniPlayer-*.flatpak
◈AMD64

Debian & Ubuntu

Install the downloaded Debian package with APT.

sudo apt install ./mpris-miniplayer_*_amd64.deb
⬡X86_64

Fedora

Install the downloaded RPM package with DNF.

sudo dnf install ./mpris-miniplayer-*.x86_64.rpm

Start an MPRIS-compatible media player, then open MiniPlayer from your application launcher.

Prefer building it yourself? Find the source and build instructions on GitHub ↗
